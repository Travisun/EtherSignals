# 指标与报告解读标准（Metrics Reference）

> 适用版本：signalEngine / signalOptimizer / signalCore（自进化趋势信号系统）
> 本文是所有推送、API 报告中出现的每一个数字的**权威定义**。与代码不一致时以代码为准并提 issue。

## 1. 系统组成与数据流

```

                     │
        ┌────────────▼────────────┐
        │ signalEngine（信号引擎）  │  每根收盘K线评估 → 状态机 → 频道/站内推送
        │  · 9指标加权投票 → score │
        │  · 滞回 + 确认状态机     │
        │  · 形态检测             │
        └────────────┬────────────┘
                     │ 趋势调用（trackCall）
        ┌────────────▼────────────┐
        │ signalOptimizer（自进化） │  · 到期判分（online ledger）
        │  · 在线 Hedge 单步       │  · 15分钟批量走查调参
        │  · 权重版本库 + 回滚     │  · 全部状态持久化 data/signals-optimizer.json
        └─────────────────────────┘
```

## 3. 趋势档位（Signal 列）

五档由**合成评分 score**（见 §5）与 ADX 门槛共同决定：

| 档位 | 图标 | 条件 |
|---|---|---|
| Strong Up 强势上涨 | ↑↑ | score ≥ +0.42 且 ADX ≥ 20 |
| Up 上涨 | ↑ | score ≥ +0.16 |
| Range 震荡 | → | score ∈ (−0.16, +0.16) |
| Down 下跌 | ↓ | score ≤ −0.16 |
| Strong Down 强势下跌 | ↓↓ | score ≤ −0.42 且 ADX ≥ 20 |

两道防抖机制（这就是为什么你不会看到频繁翻转）：
- **滞回带**：已确立的趋势要退出到震荡，需要 score 回落穿过更窄的 ±0.08（而非 ±0.16）——趋势对轻微回撤有韧性
- **确认根数**：2m/5m 的新趋势必须**连续 2 根收盘 K 线**维持才确认（30m/2h/1d 为 1 根）

分析只在**已收盘** K 线上进行，形成中的 K 线永不参与。

## 4. Win% 列（延续胜率）——最容易误读的数字

**定义**：把最近 ~300 根收盘 K 线逐根回放：每当该周期出现与当前相同的趋势档位，检查其后 `HORIZON_BARS=3` 根 K 线内价格是否朝该方向移动超过 `0.5×ATR`。历史命中的比例（Laplace 平滑 + **时间衰减加权**，半衰期 250 根）就是 Win%。

**正确解读**：
- `1d ↓↓ Strong Down 36%` = 「日线强势下跌」这个状态在历史上出现时，36% 的情况价格在 3 根内继续深跌超过阈值
- **它不是"下一步涨跌概率"**，而是这类状态的历史延续命中率
- **低于 50% 是常态且有信息量**：分母包含"3 根内没走出方向"的噪音样本（约 23%）；震荡行情里全体档位都会被压低——模型在如实报告此刻没有动量优势
- **对比要纵向看**：同一周期 Strong Down 从 25% 升到 45%，说明近期下跌趋势的延续性在变强

**计算细节**：`prob = (加权命中数 + 1) / (加权样本数 + 2)`（Laplace 平滑防 0/1 极端），原始样本数 <15 时显示 `—`（不输出不可信的数字）。

## 5. Score 与 9 个指标投票

`score = Σ(权重ᵢ × 投票ᵢ) / Σ权重ᵢ ∈ [-1, +1]`。每个指标输出 [-1,1] 的连续投票（看多正、看空负），权重初始值如下（自进化机制会按证据持续调整）：

| 指标 | 初始权重 | 投票逻辑 |
|---|---|---|
| ema_stack | 1.4 | 收盘价 vs EMA20、EMA20 vs EMA50、EMA50 vs EMA200 三重排列 |
| adx_dmi | 1.4 | ±DI 方向 × ADX 强度（18→40 线性门控，弱趋势几乎不投票） |
| macd | 1.2 | 柱线值 / ATR × 3 截断 |
| supertrend | 1.2 | SuperTrend(10,3) 方向（刚翻转时满票 1.0，持续 0.85） |
| linreg_drift | 1.1 | 20 根最小二乘斜率 / ATR × 20 截断 |
| volume_flow | 0.8 | 近 10 根多空成交量比 |
| rsi | 0.7 | (RSI−50)/20；RSI>72 或 <28 时封顶（衰竭折价） |
| boll_pctb | 0.6 | 布林 %B 位置；出带时折价到 ±0.3 |
| kdj | 0.6 | (K−D)/15 截断 |

快照中的 `adx` / `rsi` 字段是原始指标值（ADX(14) 与 RSI(14)），供交叉参考。

## 6. Patterns（形态清单）

形态是**当根收盘 K 线上触发的事件**（存在性随 K 线推进而出现/消失），每项的概率 = 该形态历史上 3 根内朝预示方向走出 0.5×ATR 的衰减加权胜率：

| key | 中文 | 触发条件 | 方向 |
|---|---|---|---|
| ema_align_bull | EMA多头排列 | EMA20>EMA50>EMA200 | 多 |
| ema_align_bear | EMA空头排列 | EMA20<EMA50<EMA200 | 空 |
| macd_golden | MACD金叉 | 柱线上穿 0 | 多 |
| macd_dead | MACD死叉 | 柱线下穿 0 | 空 |
| st_flip_bull | 超级趋势转多 | SuperTrend 翻多 | 多 |
| st_flip_bear | 超级趋势转空 | SuperTrend 翻空 | 空 |
| rsi_recovery | RSI超卖回升 | 前根 <30 且本根 ≥30 | 多 |
| rsi_fade | RSI超买回落 | 前根 >70 且本根 ≤70 | 空 |
| donchian_break_up | 唐奇安向上突破 | 收盘 > 前 20 根最高 | 多 |
| donchian_break_down | 唐奇安向下突破 | 收盘 < 前 20 根最低 | 空 |
| bb_squeeze | 布林收口 | 带宽处于近 120 根最低 15% 分位 | 中性（赌变盘幅度而非方向，命中=3 根内波动超 1.2×ATR） |

概率为 `—` 表示历史样本 <15，不足以下结论（诚实标注，不编造数字）。

## 7. Levels 区块（关键价位）

两组客观算法的并集，每个都是公开标准公式，无任何拟合参数：

**经典 Pivot 组**（基于上一**已完成**交易日的 H/L/C）：
```
PP = (H+L+C)/3
R1 = 2·PP−L      S1 = 2·PP−H
R2 = PP+(H−L)    S2 = PP−(H−L)
R3 = H+2·(PP−L)  S3 = L−2·(H−PP)
```

**Donchian-20**：最近 20 根**已收盘**日线的最高/最低（不含当根形成中的日线）——日级突破的关键口。

展示规则：
- `Resistance` = 现价上方最近的合并层级，`(+x.x%)` = 距现价百分比
- `Support` = 现价下方最近的合并层级
- `BREAKOUT`/`BREAKDOWN` = 现价已越过 Donchian 上/下沿（日线级别突破进行中）；`inside` = 区间内

用途提示：Pivot 适合日内参考，Donchian-20 突破适合趋势确认——两者重合的价位是最强关口。

## 8. 自进化模型（信号如何"自己变聪明"）

### 8.1 双速学习

| 层 | 频率 | 数据 | 作用 |
|---|---|---|---|
| **在线步** | 每笔判分即时 | 单样本 | η=0.35 的小步 Hedge 更新，分钟级贴合行情 |
| **批量走查** | 15 分钟 | ~300 根全窗回放 | η=0.8 + 每指标 ≥120 样本门槛，小时级纠偏 |

**Hedge（乘性权重）更新**：每个指标是"专家"，单样本损失 `L=(1−结果×投票)/2 ∈ [0,1]`；`w ← w × exp(−η×(L−0.5))`——比随机猜（0.5）准则加权、差则降权，0.5 居中不动。

### 8.2 防过拟合护栏（科学性核心）

1. **收缩先验**：批量更新后所有权重向基准值回拉 5%（在线步 1%）——多轮累积也不会漂进过拟合角落
2. **钳制**：权重硬边界 [0.3, 2.2]，任何单一指标无法垄断合成评分
3. **归一化**：每轮权重均值回归 1.0，合成评分尺度跨期可比
4. **样本门槛**：批量更新要求每指标 ≥120 个决定性样本；2h 窗口不足时自动跳过
5. **时间衰减**：所有概率统计近期样本权重指数级高于远古样本（半衰期 250 根）
6. **版本库 + 回滚**：每次权重变更记为版本（JSONL 永久留存）；当前版本实盘胜率 <1/3（≥12 决定性样本）而某历史版本 ≥1/2 时自动回滚，每周期冷却 2 小时

### 8.3 版本库语义

`optimizer.versions[tf]` 每项 = 一个历史参数模型 + **它自己的实盘战绩**（wins/n，判分归因于产生调用的版本，详见 `data/signals-weights-history.jsonl` 全量留档）。

## 9. 两套准确率口径（务必区分）

| 口径 | 在哪 | 分母 | 用途 |
|---|---|---|---|
| **Replay 自准确率** | 🧠 调参通知、calibration 的 `selfAccuracy` | 回放窗口内所有"有评分"的 bar（含噪音 bar，故数值偏低） | 衡量权重更新前后的**相对**改善 |
| **Online 实盘判分** | `optimizer.online[].accuracy`、看板 `accuracy` | 实际发出的趋势调用，按决定性结果判分 | 衡量**真实预测力**——这是最值得盯的数字 |

两者都是诚实度量但语义不同：调参通知里的 `27%→28%` 看相对变化即可；判断模型好坏看 online 的 `wins/calls`。

## 10. 已知局限（诚实清单）

1. **样本非独立**：连续 bar 的结果高度相关，胜率的统计置信区间比表面样本数暗示的宽——把 n=100 当 n≈30 看待
2. **单一品种拟合**：权重按 ETHUSDT 合约学习，换品种建议删 `data/signals-optimizer.json` 重新进化
3. **短线噪声下限**：2m 周期的方向预测天然接近随机，模型的价值在于 Strong 档过滤与多周期共振，而非单周期方向
4. **Replay 自准确率是 in-sample 的**：权重在同一段数据上拟合+评估，只用于观察相对变化；真实 edge 看 online ledger
5. **概率≠保证**：Win% 是历史频率，未来分布可以改变（这正是时间衰减存在的原因）

## 11. 调参指南

| 想调整 | 位置 | 建议方向 |
|---|---|---|
| 趋势灵敏度 | signalCore `ENTER_TREND`/`ENTER_STRONG` | 调高→信号更少更稳；调低→更灵敏更多噪声 |
| 防抖强度 | `CONFIRM_BARS`、`EXIT_TREND` | 翻转太频繁→调大 |
| 判分标准 | `HIT_ATR` | 调高→概率更严格、样本减少 |
| 学习速度 | optimizer `HEDGE_ETA`/`ONLINE_ETA`/`*SHRINKAGE` | 感觉权重漂移太快→调大收缩 |
| 观察窗口 | `ACQUIRE_LIMIT[tf]` | 影响回放样本量 |
| 品种/开关 | `GT_SIGNAL_SYMBOL`/`GT_SIGNAL_MARKET`/`GT_SIGNALS` | 环境变量 |

**任何调整后**跑 `GET /api/signals?view=calibration` 对比 `selfAccuracy` 与 `flipsPer100Bars`（稳定性），并在跑数小时后查看 `optimizer.online` 的实盘判分——这是验证调整是否真正有效的唯一标准。

## 12. 新高新低阶梯（NHNL Ladder）

> 位置：交易页「新高新低」条带 · REST `GET /api/market/levels?marketType&symbol&donN` · Socket 推送 `levels:update`
> 周期阶梯：`1m 1h 4h 8h 12h 1d 2d 3d 1w 1M`（8h/2d 为本地合成档）
> 计算位置：服务端 `levelsService`（任一阶梯窗口更新 → 500ms 节流推送），浏览器不直连交易所

每个周期一行（`NhnlRow`），全部针对**实时价 price**（1m 未收盘 K 的最新 close，tick 级）评估：

| 字段 | 含义 | 判定式 |
|---|---|---|
| `nh` / `nl` | **本K新高/新低**：现价正处于当前未收盘 K 柱的运行最高/最低点 | `price ≥ bar.high`（bar 极值已含最新 tick，等价于现价即本K最高） |
| `brkUp` / `brkDown` | **破前K高/低**：现价突破上一根收盘 K 柱高/低点 | `price > prev.high` |
| `donUp` / `donDown` | **破 N 根通道**：现价突破前 `donN` 根收盘 K 的 Donchian 通道（默认 20；`donN=1` 即退化为破前K） | `price > max(前N根high)` |
| `barHigh/barLow` | 当前未收盘 K 的运行高/低 | — |
| `prevHigh/prevLow` | 上一根收盘 K 的高/低 | — |
| `donHigh/donLow` | Donchian 通道上下沿 | — |
| `distHighPct/distLowPct` | 现价距本K高/低点的百分比距离（0 即 nh/nl 成立） | `(bar.high−price)/price×100` |

**跨图解读**：多周期同时 `nh`+`donUp` = 共振突破（强）；仅小周期 `nh` 而大周期 `distHighPct` 仍大 = 小级别推进、大级别未破（回参考）。

**同口径策略条件**（实时引擎与回测一致）：`price_new_high` / `price_new_low`（本K）、`donchian_break_up` / `donchian_break_down`（`bars` 参数，N 根通道）。配条件的 `tf` 覆盖即成跨图条件。

**数据来源**：阶梯窗口由服务器 `CandleService` 持有（8 个原生频道 + 8h/2d 本地聚合），历史深度由分层历史库（`data/market/*.jsonl`：1m≈5.5天 / 1h≈166天 / 1d≈6.8年）支撑；`8h` 自 1h 聚合、`2d` 自 1d 聚合（UTC 对齐分桶）。

**已知局限**：阶梯仅在服务器持有该品种全部 10 个窗口时完整（首次订阅需数秒填窗）；`1M` 行深度受交易所历史可得性限制；Donchian 用收盘 K 极值，不含盘中插针以外的未来数据（无前视）。

### 12.1 NHNL 进入自学习闭环与推送模板（2026-10-18）
